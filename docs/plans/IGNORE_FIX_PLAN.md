# Виправлення ігнорування та перевірка стабільності

Дата: 2026-10-11. Початкові ревізії: журнал `2454951` (1.3.1), тести `2ec6759` (1.5.4), завдання `cf77092` (4.4.1). Усі три checkout — чисті, гілка main.

1. Прибрати з активного зіставлення картки, для яких залишилися тільки ігноровані результати. Інші дати та учнів без отриманих оцінок залишити доступними. Відновлення повертає запис у чергу без автоматичного виставлення оцінки.
2. Не імпортувати ігнорований результат повторно, навіть після виправлення у джерелі; зберегти його нову версію для перегляду. Забезпечити серверну перевірку прав.
3. Виправити меню біля номера учня: видимість поверх закріплених колонок і меж прокрутки, керування клавіатурою, статус «Ігноровано» та відновлення. Ігнорування учня стосується лише цього журналу.
4. Запустити регресійні та повні перевірки трьох актуальних Docker-образів, перевірити PostgreSQL, HTTP-обмін та незалежну роботу на вигаданих даних. Перевірити відповідність версій коду, документації та OCI-позначень.
5. Оновити описи й зафіксувати власні зміни. Після успішних перевірок опублікувати main відповідних репозиторіїв і застосувати штатне оновлення з резервними копіями, без видалення томів. Перевірити health, статику, дані й журнали запуску.

Фактичні результати та межі перевірок додаються після виконання до INTEGRATION_CHECKS.md. Робочі дані та запити запису до nz.ua не використовуються для тестування.

Усі п’ять кроків виконано: регресії виправлені, повні й PostgreSQL-тести пройшли, HTTP-сценарій містить 47 успішних етапів. Зміни опубліковані в main; штатні HTTPS-оновлювачі перезібрали всі образи на обох хостах. Копії, правильні версії, health, статика, адреси й збереження даних перевірені. Детальний звіт — INTEGRATION_CHECKS.md. Візуальний огляд і реальний запис у nz.ua не виконувалися.
