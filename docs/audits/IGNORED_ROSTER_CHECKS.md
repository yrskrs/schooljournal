# Виключення ігнорованих учнів зі списків завдань і тестів — 1.3.13

Дата: 12.10.2026.

Причина: при ігноруванні учня в журналі відмінність у написанні імені на підключеному сайті могла створювати конфлікт замість деактивації; тимчасова недоступність сайту залишала застарілий список учнів; ігноровані учні мали зникати зі списків учителя, лічильників класу, автодоповнення, експорту CSV та API списку журналу зі збереженням ID та історії робіт при відновленні.

Виконано:

- **Ігнорування як окрема зміна участі**: у `school_sync/journal_roster.py` передача ігнорування учня змінює статус `active` без вимоги вирішення конфліктів написання імені. Нові ігноровані учні не створюються у джерелі. При відновленні повертається той самий локальний ID зі збереженням місцевого написання.
- **Підтвердження вилучення в контракті**: `roster_transfer.py` додає прапорець `ignored` до payload списку учнів та перевіряє, що джерело з підтримкою `journal_roster_ignore` підтвердило вилучення учня (`active: false`). У локальному кеші неактивні й ігноровані учні своєчасно очищаються.
- **Повторна передача списку перед отриманням оцінок**: перед стягуванням оцінок через `pull_external_grades` та `pull_source_grades` журнал автоматично повторює передачу списку, щоб застосувати зміни після тимчасової недоступності джерела. Помилка списку виводиться окремим повідомленням і не блокує отримання оцінок.
- **API списку учнів журналу**: `student_list_api` у `views_integrations.py` виключає учнів із `ignored_students`.
- **Звіт передачі списку**: у формі `connect_source` та шаблоні `connect_source.html` відображається лічильник виключених ігнорованих учнів.
- **Сумісність**: підтримка виправленого списку й лічильників на сайтах потребує SchoolNet 4.4.5 та SchoolTest 1.5.7. Нових міграцій БД немає.
