# Перевірка релізу 1.3.31 — 18.10.2026

Реліз виправляє передачу списків учнів і додає знеособлені діагностичні звіти. Публічний документ описує код і перевірки; робочі звіти конкретного встановлення та резервні копії зберігаються приватно й не входять до Git.

## Виправлення

- ID підтвердженого списку відокремлено від псевдонімів, потрібних для імпорту результатів. Вибирається відповідність із підтвердженого звіту того самого сервісу та класу; без такого звіту допускається один однозначний числовий ID. Текстові псевдоніми не передаються як native ID, а неоднозначність зупиняє запит до мережі.
- Підтвердження й об’єднання додаткових профілів більше не видаляють решту відповідностей учня. Ігнорований учень із раніше підтвердженим ID залишається в передачі як неактивний навіть після втрати локальної відповідності.
- Обробник форм розпізнає JSON: показує успіх чи пояснення відмови й оновлює журнал без переходу GET на маршрут POST. Це усуває HTTP 405 після успішної передачі й загальне повідомлення замість причини HTTP 400.
- У Центрі API доступний JSON-звіт із версією, кількостями, кодами та HTTP-статусами. Доступ перевіряється за правом керування журналом. ПІБ, оцінки, ID учнів, ключі, адреси й сирі відповіді не серіалізуються; відповіді мають Cache-Control: no-store.
- Команда `python manage.py audit_integrations` лише читає всі локальні класи, учнів і підключення; не виконує мережевих запитів і змін у БД.
- Кеш JavaScript оновлюється за хешем вмісту. Повідомлення показуються через textContent, щоб дані відповіді не перетворювалися на HTML.

## Перевірки

- Повний набір із 534 тестів успішний локально та в ізольованому образі на SQLite. Дев’ять нових перевірок охоплюють вибір підтверджених ID, псевдоніми, ігнорування, збереження відповідностей, захист доступу та приватність звітів.
- Шість сценаріїв JavaScript перевіряють JSON-успіх, відмову, попередження, непідтверджену відповідь та HTML-переходи. Сценарій додано до GitHub Actions. Наявні 16 перевірок життєвого циклу запитів і прокручування також проходять.
- На дозволеному встановленні виконано реальну передачу списків до обох типів джерел: усі відповіді HTTP 200. Отримання та імпорт оцінок під час цієї перевірки заблоковані. Контрольні суми підтвердили збереження оцінок, робіт, відповідей і попередніх відповідностей.
- Дані розбіжностей написання, неоднозначних відповідностей і конфліктів оцінок залишаються для рішення вчителя; успішний HTTP-запит не означає їх автоматичного вирішення.

Нових міграцій немає. Повний набір тестів цього релізу використовує SQLite; стан робочого PostgreSQL перевірявся читанням і контрольними сумами, без запуску тестів на робочій БД. Платний ШІ та nz.ua цим релізом повторно не перевірялися.

## Оновлення

Версія узгоджена у VERSION, RELEASES.json, CHANGELOG.md, README, Dockerfile та стандартному образі Compose. Сторінки `/versions/`, `/help/` і розділ оновлень використовують ці метадані.

Оновлюйте через штатний розділ «Оновлення системи» або `./update.sh` із чистого checkout гілки main. Штатний процес створює резервну копію. Для встановлення з попереднім локальним виправленням спочатку збережіть його зміни через git stash; змонтовані .env, медіа й робочі томи до stash не включаються. Відновлення БД для переходу на цей реліз не потрібне.
