# Виправлення порожнього списку «Ваш клас» — 1.3.12

Дата: 12.10.2026.

Причина: попередній список класів використовував лише школу й навчальний рік із серверних налаштувань фонового обміну. За стандартних нульових значень він залишався порожнім, хоча журнали й класи вчителя існували. Особистий профіль nz.ua без локальної школи також не міг скористатися таким вибором.

Виконано:

- Основний «Ваш клас» отримує класи з доступних неархівних журналів поточного користувача. Вибір показує журнали предметів лише цього класу. Чужі профілі та класи не відображаються.
- Додано три зрозумілі кроки: вибрати клас, передати учнів через журнал потрібного предмета, окремо отримати оцінки в журналі.
- Показано підключені джерела, їхній стан, час останньої передачі та кількість ігнорованих учнів. Передача виконується явною POST-кнопкою через чинний захищений маршрут підключення.
- Порожній стан пропонує створити або імпортувати журнал. Фоновий обмін і конфлікти відкриваються окремим блоком; неналаштований обмін має пояснення.
- GET сторінки не викликає повне захоплення змін, не переписує спільних списків і не утримує транзакційне блокування. Великі списки мають пагінацію по 50 записів; зіставлення учнів підготовлюються лише там, де потрібні.
- Назву розділу в навігації узгоджено зі сторінкою. VERSION, RELEASES.json (/versions/), CHANGELOG, README та /help/ оновлені. Нових міграцій немає.

Перевірки виконані на вигаданих даних у локальному Docker:

- 8 цільових регресій вибору без серверної конфігурації, особистого профілю nz.ua, порожнього стану, ізоляції доступу, явної передачі без запиту при відкритті, пагінації та чинного POST фонового обміну.
- 454 серверні тести успішно пройшли на окремому PostgreSQL у Docker; Django check та відсутність нових міграцій.
- 12 браузерних перевірок Chromium: заповнення «Ваш клас», вибір іншого класу, предмет і перехід до підключення, ігнорування, особистий профіль, мобільний екран 390 px. Неперехоплених помилок JavaScript немає.
- Навантажувальна регресія: 123 записи спільного списку, не більше 50 на сторінку та менше 25 SQL-запитів; GET не викликає capture й не створює стан обміну.

Робочий сервер недоступний. Для появи виправлення на ньому потрібно оновити розгортання до 1.3.12; заповнювати серверні параметри фонового обміну для звичайного списку класів учителя більше не потрібно.
