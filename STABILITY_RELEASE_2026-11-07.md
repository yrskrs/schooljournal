# 1.4.5: Вхід nz.ua без HTTP 405 та збереження імен

Випуск оформлює попередні виправлення стабільності й узгоджує VERSION, RELEASES.json, changelog, README, Docker-метадані та відображення версії в сайті.

- Форма входу й CSRF отримуються з головної сторінки nz.ua, а дані надсилаються POST-запитом на /login.
- Неправильний пароль розпізнається також після повернення форми на головну сторінку порталу.
- Старі профілі підключаються без помилки 500; чинні локальні ПІБ зберігаються.
- Сторінки технічних робіт і Cloudflare отримують зрозуміле повідомлення, включно з HTTP 200.

Міграцій і нових залежностей немає. Порти, томи та конфігурація Funnel зберігаються. Результати перевірок і фактичного встановлення наведено нижче.

## Причина HTTP 405

На головному сервері підтверджено: GET https://nz.ua/ повертає форму POST /login, тоді як GET /login повертає 405 та Allow: POST. Код тепер отримує CSRF із головної сторінки й надсилає форму на /login у тій самій сесії з Origin/Referer.

Окремо підтверджено відповідь 302 із Location: http://nz.ua/ після форми з порожніми полями. Обробник перенаправлень зберігає HTTPS перед виконанням наступного запиту й відхиляє перехід на сторонній origin. Форма входу, повернена на головну сторінку, більше не сприймається як успішна авторизація.

Додано тести отримання форми/CSRF, валідації на головній сторінці, справжнього механізму requests-redirect через фіктивний адаптер і заборони сторонніх адрес. Реальні логін/пароль користувача не використовувалися; успішна авторизація конкретного акаунта потребує повторної спроби користувача.

## Перевірки та встановлення

07.11.2026 встановлено `schooljournal-web:1.4.5-88162a0` на 192.168.1.13, ревізія `88162a0`. Контейнери healthy, залежності збігаються з попереднім образом.

- 713 тестів пройшли, включно з отриманням форми на /, CSRF, поверненням помилкової форми на / та HTTPS-перенаправленнями.
- Перевірено VERSION/RELEASES.json, джерело версії в коді, README, Docker/Compose та видимі номери й описи в сайтах. Контрольні суми файлів усередині контейнерів збіглися з локальними комітами.
- Попередні образи, код, конфігурації та перевірені дампи PostgreSQL збережено в `/home/yrsadmin/school-deployments/release-20261107-194829/schooljournal`.
- Конфігурація Tailscale Funnel, порти, томи, мережі й команди запуску збережені. Відбитки навчальних даних незмінні; у службових таблицях синхронізації змінювалися лише last_success/next_retry/failures/last_error, що звірено з дампами.
- GitHub push і публікація GitHub-релізу не виконувалися.

Реальна проба нового коду без облікових даних: GET https://nz.ua/ → 200, POST https://nz.ua/login → 302, GET https://nz.ua/ → 200. Код коректно повернув «Невірний логін або пароль», усі запити залишилися HTTPS, 405 не було. Успішний вхід у конкретний акаунт не перевірявся.

Під час встановлення виправлено права публічних bind-mounted VERSION, RELEASES.json і CHANGELOG.md на 0644: приватна umask сценарію патча спочатку залишила їх 0600, через що health-check журналу повертав 500. Після виправлення health-check 200 з версією 1.4.5; права .env не змінювалися.
