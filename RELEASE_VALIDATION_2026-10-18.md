# Перевірка релізу 1.3.30 — 18.10.2026

Обсяг: локальний код, власні синтетичні дані, ізольовані PostgreSQL/SQLite та локальні Docker-контейнери. Продуктивний сервер не змінювався. Ключі, .env, резервні копії та дані учнів не публікуються.

## Результати

- Повний набір: 525 тестів на PostgreSQL і стільки ж на SQLite; успішно. На SQLite у SchoolWork пропускаються дві перевірки блокування рядків, які проходять на PostgreSQL.
- Операційні тести: 19 перевірок оновлення, блокування та мережевих псевдонімів; для журналу одна перевірка вибору .env-образу пропущена, оскільки він має окремий механізм вибору.
- 31 браузерна перевірка через Nginx; 73 перевірки розкладу, 13 меню учня та 16 життєвого циклу запитів у Node. Мобільна шапка знову проходить обмеження висоти; немає необроблених помилок JavaScript.
- AST усіх відстежуваних Python-файлів, Bash-синтаксис, власний JavaScript, узгодженість метаданих версії та git diff --check перевірені.
- Нові образи зібрано з Git-джерел без робочих томів, .env і datadump.json. pip check успішний.

Міжсервісний стенд перевіряє незалежні сесії трьох сайтів, підтвердження відповідностей, окремі кнопки імпорту, повтори без дублів, захист ручних оцінок, помилки шкали, offline/retry, конфлікти, зміну IP, перезапуск і пагінацію 501 результату. Тести узгоджені з поточною політикою: непов’язані імена залишаються окремими учнями, не зараховуються до класу за схожістю ПІБ.

Файловий HTTP-сценарій: DOCX, XLSX, PPTX, PDF, PNG, TXT, HTML, CSS, JS, ZIP, SB3, HEX, WAV — приймання, перегляд і завантаження; Office-конвертація; ZIP з усіма 13 файлами; допустима й недопустима оцінка; JSON import/export. Штатна оптимізація PNG у WebP змінює байти файла; тест враховує формат і розміри зображення.

## Межі перевірки та розгортання

Живі виклики платного ШІ та nz.ua не виконувалися: контракти перевіряються контрольованими відповідями. Відео, Access і сторонні платформи не отримують заяви про повну перевірку в браузері. Успішний набір тестів не гарантує відсутності всіх можливих помилок.

Перед локальним оновленням створено й перевірено штатну резервну копію, збережено попередній образ застосунку та приватну конфігурацію. Основні записи й томи звіряються до та після оновлення; тестові дії в наявних контейнерах використовують лише власні тимчасові записи.

Опис змін: CHANGELOG.md, RELEASES.json та довідка сайту (для SchoolWork також feed/changelog.py). Для розгортання використовуйте штатний README і резервування перед update. Публікація коду на GitHub не виконує розгортання на сервері. Відкат БД скасовує записи після її знімка; відповідну копію слід обирати явно.
