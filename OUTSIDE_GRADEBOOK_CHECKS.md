# Таблиця окремих учнів — 1.3.25, 2026-10-15

На `/outside-students/?journal=ID` тепер є таблиця журналу: учні у рядках, дати й теми уроків у стовпцях, збережені роботи та оцінки в клітинках. Перегляд нічого не створює й не змінює в навчальних даних.

## Причина порожньої сторінки

Попередня сторінка мала тільки картки й відбирала учнів лише з увімкнених підключень. Якщо вчитель об’єднав нові записи зі старою канонічною ідентичністю, а старе підключення вимкнув, учні й усі перенесені роботи зберігалися в БД, але зникали з каталогу. Те саме обмеження було в черзі відповідностей, тому посилання на збережені роботи також не показувало учня.

Призупинення підключення тепер припиняє отримання нових даних, але не приховує збережену історію. Канонічні ID та підтверджені відповідності залишаються незмінними. Тезки з різними ID не об’єднуються за ПІБ.

## Робота з таблицею

1. У «Окремі учні та їхні оцінки» оберіть основний журнал. У його меню «Підключення та імпорт» також є пряме посилання **«Таблиця окремих учнів»**.
2. ПІБ закріплені зліва, дати й теми — зверху. На вузькому екрані прокручуйте саме таблицю. Якщо за дату є кілька різних робіт, вони показані окремо в клітинці.
3. Пошук, джерело, семестр та місяць змінюють перегляд. «Скинути пошук і період» зберігає вибраний журнал. Якщо окремих учнів ще немає, видно його календар і пояснення порожнього стану.
4. Якщо для роботи немає уроку або на цю дату кілька уроків без указаного номера, робота має окремий стовпець за датою. Система не вгадує номер і не створює урок автоматично.
5. Клік оцінки відкриває всі роботи відповідного учня. «Відповідності та всі роботи» веде до черги підтверджень. Для наявного окремого журналу доступне редагування; збережена ручна оцінка в ньому має пріоритет над старим результатом джерела.
6. Картки та останні роботи доступні у згортальному розділі під таблицею. Журнали інших класів не додаються до вибраного журналу.

## Перевірки

- **484 Django-тести** на окремій SQLite: весь набір журналу, включно з 12 новими перевірками таблиці.
- **42 тести на PostgreSQL 16**: таблиця, історичні записи, окремі учні та рішення вчителя.
- Нові сценарії: вимкнений канонічний запис із чинним псевдонімом; всі роботи в клітинці; відсутній або неоднозначний урок; фільтри; тезки; ігноровані результати; старі окремі учні без API-ідентичності; ручні оцінки; дубль тієї самої роботи у двох підключеннях; порожній календар; відсутність доступу чужого вчителя.
- **Chromium із Django, Gunicorn та Nginx**: таблиця, реальна CSS-статика, пошук, місяць, скидання, перехід до канонічних робіт і повернення з основного журналу. Екрани 1280×900 і 390×844; ПІБ закріплені, сторінка не виходить за межі екрана, JavaScript-помилок немає.
- Django system check та перевірка міграцій пройшли; зміни схеми БД не потрібні. Тести допоміжних скриптів оновлення пройшли; одна перевірка пропущена штатно.

Тести використовували синтетичні імена й окрему БД. Перегляд не створив нових класів, учнів, уроків або оцінок. Докази: [результати браузера](reports/outside_gradebook_2026-10-15/browser_checks.json), [ПК](reports/outside_gradebook_2026-10-15/outside_grid_desktop.png), [телефон](reports/outside_gradebook_2026-10-15/outside_grid_mobile.png).

## Відтворення

```bash
.venv/bin/python manage.py test tests --settings=config.test_settings --noinput
.venv/bin/python manage.py makemigrations --check --dry-run --settings=config.test_settings
docker build --build-arg APP_VERSION=1.3.25 -t schooljournal-outside-grid-check:1.3.25 .
docker compose -p schooljournal-outside-grid-check -f tests/ux/outside_grid.compose.yaml up -d --wait nginx
docker compose -p schooljournal-outside-grid-check -f tests/ux/outside_grid.compose.yaml exec -T journal python manage.py test tests.test_outside_gradebook tests.test_outside_students tests.test_extra_decisions --noinput
docker compose -p schooljournal-outside-grid-check -f tests/ux/outside_grid.compose.yaml exec -T journal python /app/tests/ux/seed_outside_grid.py
# Запустіть tests/ux/outside_grid_check.cjs у Playwright 1.56.1,
# у мережі schooljournal-outside-grid-check_default із доступом до nginx:80.
docker compose -p schooljournal-outside-grid-check -f tests/ux/outside_grid.compose.yaml down -v
```

`seed_outside_grid.py` дозволяє лише тестові host/name/user PostgreSQL. Тестовий Compose не має робочих портів, файлу `.env` або робочих томів; є лише власна тимчасова БД та том синтетичної статики. Seed запускається один раз у новій тестовій БД.

Штатне встановлення створює резервну копію та перевіряє готовність нового образу. Виправлення не потребує повторного імпорту оцінок чи переприв’язки реальних учнів.
