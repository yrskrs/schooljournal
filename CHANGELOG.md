# Історія версій

## 1.3.1 — 2026-10-11

- Позакласні учні та результати: додано можливість ігнорувати запис або оцінку саме за вибрану дату з перенесенням до збереженого розділу «Ігноровані записи та оцінки» та можливістю відновлення в будь-який момент.
- При виборі «Залишити позакласним» автоматично створюється окремий журнал (таблиця) для позакласних учнів з їхніми роботами та оцінками.
- Синхронізація з nz.ua (Нові знання): додано кнопку «Ігнорувати запис» навпроти учня/запису у вікні змін для вивантаження, щоб зміни заблокованих дат не позначались як невивантажені.
- Кабінет вчителя («Мої навчальні журнали»): збережено класичне відображення плитками та додано можливість вільно змінювати їхню послідовність перетягуванням (Drag & Drop) із збереженням порядку в профілі.
- Таблиця журналу: дію «🚫 Ігнорувати при синхронізації» перенесено до номерації учня (клік на номер відкриває меню дій над учнем).

## 1.3.0 — 2026-10-11

- Один ключ API дозволяє журналу отримувати оцінки та передавати копію класу й учнів у незалежну місцеву БД джерела. Ручне введення ID та налаштування peers для цього не потрібні.
- Стабільні прив’язки, повтори без дублів, збереження історії та явні рішення для схожих імен/конфліктів. Відсутність запису не означає видалення.
- Незіставлені учні та результати збережені в позакласному списку журналу; урок визначається за датою. Статистика запитів і помилки доступні в інтерфейсі.
- API v1/v2 сумісні; нова можливість POST списків оголошується через capabilities.

- Адитивна міграція journals 0012; перед нею потрібна перевірена резервна копія. Не відновлюйте стару БД автоматично під час відкату образу.

## 1.2.2 — 2026-10-10

- Окремі cookies журналу й завдань виправляють втрату входу на одній IP з різними портами. Переноситься лише чинна сесія з власної БД; CSRF збережено.
- Адреса джерела (IP і порт) та ключ — видимі окремі поля. Старі JSON-коди також підтримуються.
- Зміна IP у чинному підключенні зберігає його ID, відповідності й оцінки; інший instance_id відхиляється без зміни даних.
- Приватні LAN Host дозволені через ALLOW_PRIVATE_NETWORK_HOSTS; сторонні домени й публічні IP потребують ALLOWED_HOSTS. Нових міграцій немає.

## 1.2.1 — 2026-10-10

- Виправлено перевірку образу з налаштуваннями Compose: JSON у лапках та багаторядкові значення підтримуються без зміни .env.
- Перевірка залишається перед зупинкою й міграціями; секрети передаються через stdin.
- Підключення за кодом та API v1/v2 сумісні з 1.2.0.

## 1.2.0 — 2026-10-10

- Майстер «Підключити тести / завдання»: готовий код або адреса й ключ → назви класів і предметів → підтвердження учнів. Оцінки отримуються лише окремими кнопками журналу.
- Постійний кеш назв не залежить від доступності джерела; міграція journals 0011 додає лише два поля підключення. Наявні списки, оцінки, ID та підключення збережені.
- Записи за ПІБ не об’єднуються автоматично: вчитель підтверджує запропоновані відповідності або явно створює нового учня.
- Оновлення через HTTPS GitHub та перезапуск nginx після зміни контейнера web. API v1/v2 і попередня форма підключення залишаються сумісними.

## 1.1.1 — 2026-10-10

- LAN-адреса додається через `./setup.sh --public-url http://192.168.1.13:8085`: дозволений хост і CSRF origin узгоджені, наявні налаштування збережені.
- Приклад конфігурації дозволяє внутрішні хости `web,schooljournal-api`; міжконтейнерний API не відхиляється через Host. Для чинної `.env` описано відповідне оновлення.
- Демонстраційне наповнення більше не створює суперадміністратора з наперед заданим паролем та не закриває перший запуск.
- Явно дозволене на сервері одноразове відновлення адміністратора через браузер зберігає PK, школи, журнали й аудит. Завершення закриває форму; секретний код і CSRF обов’язкові.
- Оновлено опис версії та Docker-образ. Змін схеми бази немає; API v1/v2 сумісні з 1.1.0.

## 1.1.0 — 2026-10-10

- Рівноправні локальні списки та API v2: явне зіставлення ID, ручні конфлікти, відновлення обміну у фоні.
- Дві кнопки імпорту остаточних оцінок у контексті класу, предмета та періоду журналу.
- Ідемпотентність, оновлення виправлень і захист ручних оцінок; лише цілі 1–12 зі шкали 12.
- Адитивні міграції, окрема Docker-мережа, контракт і відкат; початкове налаштування 1.0.1 збережено.


## 1.0.1 — 2026-10-10

- Перший суперадміністратор створюється у браузері з одноразовим кодом INITIAL_SETUP_TOKEN.
- Початкове налаштування закривається після створення адміністратора; міграція зберігає наявних адміністраторів.
- Транзакція та блокування захищають від одночасного створення двох перших адміністраторів. Видалення адміністратора не відкриває форму повторно.
- setup.sh генерує код для нового або наявного .env, зберігаючи паролі бази та інші параметри.
- Інструкції розгортання й оновлення використовують main та HTTPS. Пароль суперадміністратора більше не задається через FIRST_SUPERADMIN_PASSWORD.

## 1.0.0 — 2026-10-10

Перша документована версія, що об’єднує зміни локального журналу:

- Реєстрація школи, адміністратор власної школи та видимий вхід через nz.ua.
- Особистий NZ-профіль, локальна прив’язка/відв’язування без втрати записів.
- Онлайн-імпорт, локальна робота й контрольоване вивантаження в nz.ua.
- Підсумкові оцінки, модульна та одна загальна НУШ-оцінка.
- Шкільний час уроків і тижневий розклад.
- API учнів, зовнішні оцінки, погодження ШІ й блокування непогодженого експорту.
- Інструкція та версії на сайті, Docker, update/backup/restore, GitHub Actions.
