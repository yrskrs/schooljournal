# Вибір уроку для оцінок — перевірка 1.3.36

Перевірено 21.10.2026. Новий сценарій доступний як «Обрати урок» біля
«📥 Оцінки», у простому розділі API та в додаткових налаштуваннях підключення.

## Поведінка

- GET не викликає джерело. «Показати роботи» лише читає результати за
  період завершення, без передачі списків, зіставлення учнів та імпорту.
- Роботи згруповані за сесією тесту або завданням; однакові назви та
  повторно використаний тест з різними сесіями не об'єднуються.
- Для конкретної роботи можна обрати наявний звичайний урок свого журналу
  за датою, номером і темою. Він може бути поза періодом завершення робіт,
  але в межах навчального року. Інші роботи не імпортуються цією дією.
- Підтвердження використовує серверний перегляд поточного користувача
  зі строком дії 20 хвилин. Підміна токена, чужий урок, видалений урок,
  змінене або вимкнене підключення відхиляються. Запит захищений CSRF.
- Вибір зберігається для наступних пізніх результатів, зокрема через
  підтверджену резервну адресу. Доступне повернення до автоматичного вибору.
- Уже імпортовані оцінки не переносяться й не дублюються при зміні вибору,
  зокрема після зміни адреси того самого сайту. Ручні оцінки й відвідування
  не переписуються; конфлікт виноситься на рішення вчителя.
- Окремі учні отримують оцінки у власний журнал. Вихідні дати API та сирі
  результати не переписуються. Вибір уроку записується в аудит із вчителем.

Браузер перевіряє справжні HTTP-сторінки та POST-маршрути: спершу одна
оцінка вже стоїть на попередньому уроці, пізніший результат отримується за
інший місяць, учитель обирає попередній урок, а наступний учень потрапляє
туди вже звичайною синхронізацією. Інша робота залишається неімпортованою.
Горизонтального переповнення та помилок JavaScript не виявлено. Мобільний
і настільний вигляд перевірені за знімками.

Порядок повторення: [tests/ux/README.md](tests/ux/README.md). Знімки поточного
прогону: `/tmp/schooljournal-grade-placement-artifacts/`.

## Дані й розгортання

Міграція `journals.0019_gradelessonassignment` додає лише нову таблицю
прив'язок; наявні оцінки, учні та результати не переписуються. Ліміти
перегляду: 2000 результатів і 3 МіБ; для більшої історії звузьте період.
Прив'язка видаленого уроку або підключення видаляється разом із ним.

Основний віддалений сервер недоступний. Тестові API підмінено; чинність
робочих ключів, фактичний обмін з основним сервером та його конкретні
помилки цими перевірками не підтверджуються. Зовнішні оцінки робочої бази
під час тестів не імпортувалися. Робочі звіти залишаються локально й не
публікуються в GitHub.
