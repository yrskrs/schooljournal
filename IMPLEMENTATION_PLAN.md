- Перед міграціями створено backups/before-profile-api-update-20261010.dump з правами 0600; вміст копії не відкривався.
- Тести не зверталися до офіційного nz.ua чи реального сервера робіт. Формат майбутнього API та налаштування описано в EXTERNAL_API.md. Реальний маршрут сервера робіт користувач ще розробляє; автоматичний обмін можна ввімкнути після його появи.
